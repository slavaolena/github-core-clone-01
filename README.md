# GitHub Core Clone 01

Build a GitHub-compatible git forge.

## Features

- REST v3 API: repositories, issues, pull requests, contents
- Git Smart HTTP: upload-pack v2, receive-pack v0
- GraphQL v4 API: full introspection
- MCP endpoint: tools/list, tools/call

## Run

```bash
npx tsx main.ts
```
